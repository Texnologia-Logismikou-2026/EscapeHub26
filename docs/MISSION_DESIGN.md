# Σχεδιασμός Αποστολής (Mission Design) — EscapeHub

## 1. Γενικά Στοιχεία Αποστολής
* **Τίτλος:** Το Κρυπτογραφημένο Αρχείο της Βιβλιοθήκης (*The Encrypted Library Archive*)
* **Κατηγορία:** Μυστήριο / Ιστορική Έρευνα
* **Τρόπος Παιχνιδιού:** Ατομικά ή Ομαδικά (2–4 παίκτες)
* **Εξωτερική Πηγή Δεδομένων (Public API):** Open Library API (`https://openlibrary.org/search.json`, `https://openlibrary.org/authors/{key}.json`)

### Σύνοψη Σεναρίου
Ένας εκκεντρικός βιβλιοθηκάριος εξαφανίστηκε, αφήνοντας πίσω του ένα κλειδωμένο ψηφιακό χρηματοκιβώτιο που περιέχει ένα σπάνιο χειρόγραφο. Οι παίκτες έχουν πρόσβαση στο γραφείο του και σε τρία αρχικά στοιχεία (evidence). Για να ανοίξουν το χρηματοκιβώτιο, πρέπει να εξερευνήσουν δύο ανεξάρτητες διαδρομές έρευνας, να αντλήσουν πραγματικά βιβλιογραφικά δεδομένα μέσω του **Open Library API** και να συνδυάσουν τα ευρήματά τους στο **Shared Diary** της ομάδας.

---

## 2. Μη Γραμμική Δομή & Διαδρομές
Η αποστολή **δεν είναι γραμμική**. Μετά την έναρξη, η ομάδα μπορεί να επιλέξει ελεύθερα αν θα λύσει πρώτα τη **Διαδρομή Α** ή τη **Διαδρομή Β** (ή να χωριστεί και να τις τρέξει παράλληλα). Και οι δύο διαδρομές συγκλίνουν στο **Τελικό Στάδιο (Stage 3)**.

```text
                 [ Έναρξη: Γραφείο Βιβλιοθηκάριου ]
                  /                               \
                 v                                 v
      [ Διαδρομή Α: Το Σημείωμα ]       [ Διαδρομή Β: Η Κάρτα Δανεισμού ]
      (Αναζήτηση Βιβλίου - API)          (Αναζήτηση Συγγραφέα - API)
                 \                                 /
                  v                               v
           [ Shared Diary: Συνδυασμός Κλειδιών Α + Β ]
                                 |
                                 v
               [ Τελικό Στάδιο: Ψηφιακό Χρηματοκιβώτιο ]

## 3. Στοιχεία (Evidence), Γρίφοι & Χρήση Open Library API

### Αρχικό Στάδιο (Unlocked by default)
* **Evidence #1 (Ημερολόγιο Γραφείου):** Περιέχει το μήνυμα: *«Η αλήθεια κρύβεται στο πρώτο έτος έκδοσης του μεγάλου ταξιδιού και στη χρονιά που γεννήθηκε ο δημιουργός της φρίκης.»*
* **Evidence #2 (Σκισμένη Σελίδα — Διαδρομή Α):** Αναφέρει τον τίτλο *"Twenty Thousand Leagues Under the Sea"*.
* **Evidence #3 (Παλιά Κάρτα Αρχείου — Διαδρομή Β):** Περιέχει έναν κωδικό συγγραφέα ή όνομα: *"Mary Shelley"*.

### Διαδρομή Α: Το Έτος του Ταξιδιού (Puzzle A)
* **Στόχος:** Οι παίκτες πρέπει να βρουν το **έτος πρώτης έκδοσης** (`first_publish_year`) του βιβλίου *"Twenty Thousand Leagues Under the Sea"*.
* **Ουσιαστική Χρήση API:** Το σύστημα (ή ο παίκτης μέσω της ενσωματωμένης αναζήτησης του EscapeHub) καλεί το endpoint:
  `GET [https://openlibrary.org/search.json?title=Twenty+Thousand+Leagues+Under+the+Sea](https://openlibrary.org/search.json?title=Twenty+Thousand+Leagues+Under+the+Sea)`
* **Επικύρωση (Validation):** Το backend επικυρώνει την απάντηση του παίκτη συγκρίνοντάς την δυναμικά με το πεδίο `first_publish_year` που επιστρέφει το Open Library API (π.χ. `1870`).
* **Ανταμοιβή:** Ξεκλειδώνει το **Evidence #4 (Κλειδί Α)** και αποθηκεύεται αυτόματα/χειροκίνητα σημείωση στο Shared Diary.

### Διαδρομή Β: Η Ταυτότητα του Δημιουργού (Puzzle B)
* **Στόχος:** Οι παίκτες πρέπει να εντοπίσουν το **έτος γέννησης** (`birth_date`) της συγγραφέως *"Mary Shelley"* και τον αριθμό των καταχωρημένων έργων της ή το πιο γνωστό της έργο (`top_work`).
* **Ουσιαστική Χρήση API:**
  1. Αναζήτηση συγγραφέα: `GET [https://openlibrary.org/search/authors.json?q=Mary+Shelley](https://openlibrary.org/search/authors.json?q=Mary+Shelley)` -> ανάκτηση του `key` (π.χ. `OL26444A`).
  2. Λεπτομέρειες συγγραφέα: `GET [https://openlibrary.org/authors/OL26444A.json](https://openlibrary.org/authors/OL26444A.json)` -> εξαγωγή του `birth_date` (`1797`).
* **Επικύρωση (Validation):** Το backend ελέγχει αν η απάντηση ταιριάζει με το έτος γέννησης από το API (`1797`).
* **Ανταμοιβή:** Ξεκλειδώνει το **Evidence #5 (Κλειδί Β)**.

### Τελικό Στάδιο: Το Χρηματοκιβώτιο (Puzzle C — Συνεργατικός Γρίφος)
* **Προαπαιτούμενο:** Πρέπει να έχουν λυθεί **και** το Puzzle A **και** το Puzzle B.
* **Μηχανισμός Συνεργασίας & Shared Diary:**
  * Σε ομαδικό παιχνίδι, ο Παίκτης 1 (που έλυσε τη Διαδρομή Α) και ο Παίκτης 2 (που έλυσε τη Διαδρομή Β) καταγράφουν τα ευρήματά τους στο **Shared Diary** (`POST /api/diary`).
  * Ο τελικός κωδικός του χρηματοκιβωτίου προκύπτει από τη **διαφορά** των δύο ετών σε συνδυασμό με τη σειρά που ορίζει το Evidence #1:
    `Κωδικός = Έτος_Α - Έτος_Β` (π.χ. `1870 - 1797 = 73` ή συνδυασμός ψηφίων `1870-1797`).
* **Σειρά Ενεργειών:** Πρέπει πρώτα να καταχωρηθεί το **Κλειδί Α** και έπειτα το **Κλειδί Β** εντός χρονικού παραθύρου ή με συγκεκριμένη σειρά υποβολής.

## 4. Κανόνες Ξεκλειδώματος (Unlock Rules)

| Στάδιο / Στοιχείο | Κατάσταση Έναρξης | Κανόνας Ξεκλειδώματος (Rule) |
| :--- | :--- | :--- |
| **Evidence #1, #2, #3** | Unlocked | Διαθέσιμα αμέσως με την έναρξη της αποστολής. |
| **Evidence #4 (Κλειδί Α)** | Locked | Ξεκλειδώνει όταν `Puzzle A == SOLVED` (επικύρωση μέσω Open Library Search API). |
| **Evidence #5 (Κλειδί Β)** | Locked | Ξεκλειδώνει όταν `Puzzle B == SOLVED` (επικύρωση μέσω Open Library Authors API). |
| **Τελικό Στάδιο (Puzzle C)** | Locked | Ξεκλειδώνει **μόνο** όταν `(Puzzle A == SOLVED) AND (Puzzle B == SOLVED)`. |
| **Ολοκλήρωση Αποστολής** | Locked | Επιτυγχάνεται όταν υποβληθεί σωστά ο συνδυαστικός κωδικός στο Puzzle C. |
