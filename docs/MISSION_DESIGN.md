# Σχεδιασμός Αποστολής (Mission Design) — EscapeHub

## 1. Γενικά Στοιχεία Αποστολής
* **Τίτλος:** Το Κρυπτογραφημένο Αρχείο της Βιβλιοθήκης (*The Encrypted Library Archive*)
* **Κατηγορία:** Μυστήριο / Ιστορική Έρευνα
* **Τρόπος Παιχνιδιού:** Ατομικά ή Ομαδικά (2–4 παίκτες)
* **Εξωτερική Πηγή Δεδομένων (Public API):** Open Library API (`https://openlibrary.org/search.json`, `https://openlibrary.org/authors/{key}.json`)

### Σύνοψη Σεναρίου
Ένας εκκεντρικός βιβλιοθηκάριος εξαφανίστηκε, αφήνοντας πίσω του ένα κλειδωμένο ψηφιακό χρηματοκιβώτιο που περιέχει ένα σπάνιο χειρόγραφο. Οι παίκτες έχουν πρόσβαση στο γραφείο του και σε τρία αρχικά στοιχεία (evidence). Για να ανοίξουν το χρηματοκιβώτιο, πρέπει να εξερευνήσουν δύο ανεξάρτητες διαδρομές έρευνας, να αντλήσουν πραγματικά βιβλιογραφικά δεδομένα μέσω του **Open Library API** και να συνδυάσουν τα ευρήματά τους στο **Shared Diary** της ομάδας.

---

## 2. Μη Γραμμική Δομή & Διαδρομές
Η αποστολή **δεν είναι γραμμική**. Μετά την έναρξη, η ομάδα μπορεί να επιλέξει ελεύθερα αν θα λύσει πρώτα τη **Διαδρομή Α** ή τη **Διαδρομή Β** (ή να χωριστεί και να τις τρέξει παράλληλα). Και οι δύο διαδρομές συγκλίνουν στο **Τελικό Στάδιο (Stage 3)**.

```text
                 [ Έναρξη: Γραφείο Βιβλιοθηκάριου ]
                  /                               \
                 v                                 v
      [ Διαδρομή Α: Το Σημείωμα ]       [ Διαδρομή Β: Η Κάρτα Δανεισμού ]
      (Αναζήτηση Βιβλίου - API)          (Αναζήτηση Συγγραφέα - API)
                 \                                 /
                  v                               v
           [ Shared Diary: Συνδυασμός Κλειδιών Α + Β ]
                                 |
                                 v
               [ Τελικό Στάδιο: Ψηφιακό Χρηματοκιβώτιο ]
