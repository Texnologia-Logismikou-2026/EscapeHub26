# Changelog

Όλες οι αξιοσημείωτες αλλαγές του EscapeHub καταγράφονται σε αυτό το αρχείο. Η έκδοση ακολουθεί [Semantic Versioning](https://semver.org/).

## [Unreleased] - v0.1.1
### Added
- `DEFINITION_OF_DONE.md` και `.github/pull_request_template.md` με πεδίο δήλωσης χρήσης AI.
- `AI_USAGE_LOG.md` για την καταγραφή χρήσης AI ανά sprint.
- Πίνακας σύνθεσης ομάδας και εναλλαγής Scrum Master στο `README.md`.

## [0.1.0] - 2026-11-19
### Added
- Αρχική δομή Spring Boot / Maven backend (`escapehub-backend`).
- Database schema entities, Auth API και Teams API.
- Mission Catalog API (`MissionController`) και Shared Diary API (`DiaryController`, `DiaryEntry`).
- Διερεύνηση Open Library API (`docs/api-exploration.md`) και αρχικός σχεδιασμός αποστολής (`docs/MISSION_DESIGN.md`).
